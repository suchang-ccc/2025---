# 2025TIcup
2025全国大学生电子设计竞赛-电路模型探究装置-一种解决方案
项目内容：根据题目给定的传递函数制作了一个滤波器模块；设计了一个能够检测未知滤波器幅频特性，并能根据输入信号模拟重建出其输出幅频响应的装置。

二阶有源滤波器的设计：使用matlab对传递函数分析，计算出增益、滤波类型、截止频率与阶数，代入设计工具求出实际的阻容值并测试调整。根据输入信号特性选择合适的电路拓扑与运放型号，解决了信号源与滤波器之间的阻抗匹配问题。

系统方案制定与模块制作：设计了信号源-射频前端-滤波器-采样保持-ADC的硬件方案，制作了通用的DCDC与LDO供电模块，根据信号的幅度与带宽设计了放大器与跟随器模块，选定DDS与ADC模块的具体型号。

系统指标：设计的有源滤波器实际频响与给定传递函数偏差小于3%；系统识别未知滤波器类型（低通高通带通带阻）准确率100%；模拟重建的输出信号与滤波器实际输出频率与幅度偏差小于5%
